# Maximum Weight Graph Matching in C++

A custom C++ solver designed to find the **Maximum Weight Matching** in undirected graphs. 

In simple terms: imagine you have a group of people (or servers, tasks, locations) connected by relationships with different values (weights). The program finds the best possible non-overlapping pairs to get the highest total combined score.

I built this project completely from scratch without using `std::vector`, `std::queue`, or ``, focusing on low-level memory allocation, pointer safety, and graph optimization algorithms.
